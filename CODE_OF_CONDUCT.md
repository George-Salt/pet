# Code of Conduct

Everyone is welcome to participate in Pet. Keep discussions respectful, give feedback about the work, and make space for people with different backgrounds and experience.

Harassment, discriminatory language, threats, unwanted sexual attention, and publishing someone else's private information without permission are unacceptable in project spaces.

Report conduct concerns privately to the maintainer through the email listed on the [maintainer's GitHub profile](https://github.com/George-Salt), if available, or use GitHub's reporting tools for abusive content. Maintainers may remove content, close discussions, or limit participation to address violations.
